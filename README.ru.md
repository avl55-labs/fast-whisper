## Быстрый старт

1. Скачайте установщик из [релизов][rel] и запустите. Без прав администратора, без UAC.
2. При первом запуске приложение спросит, какую модель распознавания использовать.
   Рекомендованная уже выбрана.
3. Поставьте курсор туда, где нужен текст, нажмите `Ctrl+Space`, скажите, нажмите ещё раз.
   `Esc` выбрасывает запись.

Текст остаётся ещё и в буфере обмена — если вставка ушла не в то окно, сказанное не
потеряно.

## Зачем

Диктовка — самый быстрый способ вынуть абзац из головы, а под Windows хорошие инструменты
для неё продаются по подписке, требуют аккаунта и отправляют ваш голос на свои серверы.

FastWhisper делает ту же работу без всего этого. Распознавание идёт на вашей машине через
[faster-whisper][fw]: голос никуда не уходит, входить некуда, платить не за что, и всё
продолжает работать с выключенной сетью.

|  | FastWhisper | Типичное платное приложение |
| --- | --- | --- |
| Цена | бесплатно, MIT | $8–15 в месяц |
| Аккаунт | не нужен | обязателен |
| Ваш голос | остаётся на машине | загружается для распознавания |
| Работа офлайн | да | нет или урезанный локальный режим |
| Развёртывание в домене | MSI для Group Policy и Intune | редко бывает |
| macOS, iOS | нет | обычно есть |
| Облачные модели, переписывание через ИИ | нет | обычно есть |

Последние две строки — честный размен: это узкий инструмент под Windows, а не комбайн.

## Что внутри

| | |
| --- | --- |
| **Одна горячая клавиша** | `Ctrl+Space` переключателем или удержанием. Можно записать любую клавишу или сочетание, включая одинокий `Right Ctrl`. |
| **Панель, на которой видно работу** | Решётка золотых зёрен колышется от голоса, а пока модель расшифровывает — меняет рисунок. Фокус не забирает, клики проходят насквозь. |
| **Десять моделей** | Whisper и Distil-Whisper, от Tiny с третью секунды на фразу до Large v3. Скачиваются и удаляются прямо в приложении. |
| **Ваши слова** | Словарь имён и терминов подсказывается модели перед каждой записью, и она перестаёт их коверкать. |
| **История** | Всё распознанное, с поиском, копируется одним щелчком. |
| **Русский и английский** | Интерфейс следует за Windows и не связан с языком, на котором вы диктуете. |

> Не связан ни с библиотекой `faster-whisper`, ни с OpenAI, ни с кем-либо ещё, чьи модели
> умеет запускать. FastWhisper — приложение, использующее открытые модели на условиях их
> собственных лицензий.

## Какую модель выбрать

Whisper прогоняет кодировщик по окну в тридцать секунд независимо ни от чего, поэтому
ожидание почти не зависит от длины сказанного: фраза на три секунды стоит примерно
столько же, сколько на девять. Замерено на восьмиядерном Ryzen 9 8945HS, `int8`,
16 потоков:

| Модель | На диске | Ожидание на фразу | Качество |
| --- | --- | --- | --- |
| `base` | ~0,15 ГБ | ~0,6 с | грубо, сойдёт для коротких английских заметок |
| `small` | ~0,5 ГБ | ~1,6 с | прилично, и самая быстрая из пригодных |
| `medium` | ~1,5 ГБ | ~4,3 с | хорошо, но Turbo лучше при той же цене |
| `large-v3-turbo` | ~1,6 ГБ | ~5,5 с | лучшее качество на процессоре — по умолчанию |
| `large-v3` | ~3 ГБ | ещё медленнее | имеет смысл только на видеокарте с CUDA |

На видеокарте NVIDIA поставьте `device` в `cuda`, а `compute_type` в `float16`: Turbo
начнёт отвечать заметно быстрее секунды, и брать что-то меньшее незачем.

## Настройки

В значке в трее лежит только то, что нужно посреди диктовки. Всё остальное — в окне
настроек, на шести страницах: **Общие** (клавиша, язык, модель, куда попадает текст),
**Звук** (микрофон, обрезка тишины, потоки процессора), **Модели**, **Словарь**,
**История** и **О программе**.

Про клавишу: одиночную вроде `Right Ctrl` удобнее всего держать, и она продолжает работать
сама собой — но тогда любое обычное её нажатие открывает микрофон. У сочетания
проглатывается только последняя клавиша, модификаторы не трогаются вовсе, так что берите
то, которое больше никому не нужно.

Всё написанное в окне сразу уходит в `%APPDATA%\FastWhisper\config.json`. Несколько
настроек живут только там:

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `hotkey` | `ctrl+space` | Клавиша или сочетание: `f9`, `right ctrl`, `ctrl+alt+space`. |
| `mode` | `toggle` | `hold` (удержание) или `toggle` (переключатель). |
| `language` | `ru` | Язык распознавания или `auto`, чтобы определять для каждой записи. |
| `output` | `paste` | `paste`, `type` (посимвольно) или `clipboard`. |
| `device` | `cpu` | `cuda`, если есть видеокарта NVIDIA и установлены библиотеки CUDA. |
| `min_seconds` | `0.4` | Записи короче считаются случайным нажатием и выбрасываются. |

Каждая настройка прокомментирована в [`fastwhisper/config.py`](fastwhisper/config.py).

## Обновления

FastWhisper умеет раз в сутки спрашивать у GitHub, не вышла ли версия новее, и сообщать об
этом. Ничего о вас и о вашей машине не отправляется, и ничего не устанавливается само:
вы нажимаете кнопку, и открывается обычный установщик с обычным окном. Галку предлагают
при первом запуске, живёт она в *Настройки → О программе*.

MSI выключает проверку для всей машины: в управляемой сети версии меняются тогда, когда
скажет администратор.

## Для организаций

`FastWhisper-x.y.z.msi` — пакет на всю машину для Group Policy или Intune. Ставится молча,
лицензий считать не надо, данные машину не покидают.

```powershell
msiexec /i FastWhisper-0.1.2.msi /qn
msiexec /i FastWhisper-0.1.2.msi /qn AUTOSTART=1 MODELDIR="C:\ProgramData\FastWhisper\models"
msiexec /x FastWhisper-0.1.2.msi /qn
```

| Свойство | Что делает |
| --- | --- |
| `AUTOSTART=1` | Запускает FastWhisper для каждого, кто входит в систему. |
| `MODELDIR=<путь>` | Один каталог моделей на машину вместо копии в каждом профиле — по полгигабайта каждая. |
| `UPDATECHECK=1` | Разрешает пользователям проверять обновления. В MSI по умолчанию выключено. |

Заполните `MODELDIR` с машины, где модель уже есть, — и приложение вообще перестанет
обращаться к сети. Клавиши, словарь и история остаются у каждого своими, в `%APPDATA%`.

## Пакеты без подписи, и что с этим делает Defender

Пакеты **не подписаны**. Сертификат стоит несколько сотен долларов в год, проект ни с кого
ничего не берёт, и денег на подпись пока нет.

Поэтому SmartScreen ругается на неизвестного издателя, а Microsoft Defender время от
времени решает, что неподписанная сборка PyInstaller — это `Trojan:Win32/Wacatac` или
`Trojan:Win32/Bearfoos`. И то и другое — ложное срабатывание эвристики, которая реагирует
на способ упаковки, а не на содержимое; Defender может отправить FastWhisper в карантин
или прибить его на ходу. Пока подписи нет, лечится исключением — от администратора:

```powershell
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\Programs\FastWhisper"
```

| Как установлено | Какую папку исключить |
| --- | --- |
| `FastWhisper-x.y.z-setup.exe` | `%LOCALAPPDATA%\Programs\FastWhisper` |
| `FastWhisper-x.y.z.msi` | `%ProgramFiles%\FastWhisper` |
| Собрано из исходников | `<репозиторий>\dist\FastWhisper` |

Жалоба на ложное срабатывание — то, что в итоге снимает его для всех:
[отправьте файл в Microsoft](https://www.microsoft.com/en-us/wdsi/filesubmission). А пока —
здесь лежит весь исходный код, у каждого релиза опубликованы SHA-256 его файлов, и вы
можете за несколько минут собрать и подписать собственную копию.

## Сборка из исходников

Нужен Python 3.11+ и, для установщика, [Inno Setup 6][inno].

```powershell
git clone https://github.com/avl55-labs/fast-whisper
cd fast-whisper
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Запустить без сборки:

```powershell
py -3 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw -m fastwhisper
```

## Если что-то не так

- **Клавиша не работает в одном конкретном приложении.** Windows не пускает клавиатурные
  хуки в процессы с более высоким уровнем целостности. Если то приложение запущено от
  администратора, FastWhisper тоже придётся.
- **Текст не вставляется.** Некоторые приложения игнорируют синтетический `Ctrl+V`.
  Переключите `output` на `type`.
- **Ничего не распознаётся.** Проверьте микрофон в `input_device`; журнал
  `%APPDATA%\FastWhisper\fastwhisper.log` пишет каждую запись и её длину.
- **Defender унёс exe.** См. [выше](#пакеты-без-подписи-и-что-с-этим-делает-defender).

## Приватность

Ни телеметрии, ни аналитики, ни отчётов о сбоях, ни аккаунта. Звук живёт только в памяти и
стирается после распознавания. Распознанный текст дописывается в
`%APPDATA%\FastWhisper\history.jsonl` — поставьте `save_history` в `false`, и он не будет.

Сетевых запросов у приложения два, и от обоих можно отказаться: разовая загрузка модели и
описанная выше проверка обновлений.
